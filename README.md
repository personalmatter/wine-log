# 🍷 와인 다이어리 (Wine Log & Vivino Sync)

아이폰으로 와인 라벨 사진을 찍으면 AI가 와인 정보를 자동으로 인식하고, 비비노(Vivino) 평점과 함께 나의 시음 노트, 안주 평점, 가격을 구글 시트 및 웹앱에 깔끔하게 기록해 주는 모바일 웹 애플리케이션입니다.

---

## ✨ 주요 기능

1. **AI 와인 라벨 자동 인식 (Vision AI)**
   - 와인 사진을 찍으면 와인명, 빈티지(생산연도), 와이너리/생산자, 품종, 지역, 와인 종류(레드/화이트 등), 도수를 자동으로 추출하여 입력 폼에 채워줍니다.
2. **비비노(Vivino) 평점 자동 검색 연동**
   - 라벨에서 인식된 와인명으로 비비노를 실시간 검색하여 비비노 평점(⭐)과 리뷰 수, 비비노 링크를 즉시 연결합니다.
3. **나의 테이스팅 & 안주 기록**
   - 마신 날짜, 구입 가격
   - 내 와인 평점 (0.5 단위 별점) 및 시음 코멘트/메모
   - 곁들인 안주 이름, 안주 평점(별점), 안주 코멘트
4. **구글 시트 & 구글 드라이브 자동 동기화**
   - 저장 시 구글 드라이브에 라벨 사진을 업로드하고, 구글 시트에 모든 데이터와 사진 링크를 한 줄로 자동 기록합니다.
   - 구글 연동이 설정되지 않아도 로컬 SQLite DB에 완벽히 저장됩니다.
5. **아이폰 모바일 최적화 (PWA)**
   - 사파리(Safari)에서 "홈 화면에 추가" 시 앱스토어 앱처럼 전체화면으로 동작하며, 카메라로 즉시 라벨을 촬영할 수 있습니다.
6. **내 와인 서고 (갤러리/피드 뷰)**
   - 지금까지 마신 와인들을 사진 카드 형태로 모아보고 관리(삭제)할 수 있습니다.

## 🚀 빠른 시작 가이드

### 1. 서버 실행하기

터미널에서 아래 스크립트를 실행합니다:

```bash
./run.sh
```

콘솔에 다음과 같이 접속 주소가 출력됩니다:
- **Mac 브라우저**: `http://localhost:8000`
- **아이폰 접속 (동일 Wi-Fi)**: `http://192.168.x.x:8000` (출력된 IP 주소)

### 2. 아이폰에서 앱처럼 설치하기 (PWA)

1. 아이폰 Safari 브라우저에서 `http://[Mac의 IP주소]:8000`에 접속합니다.
2. 하단 공유 버튼(네모에 위 화살표 아이콘)을 누릅니다.
3. **'홈 화면에 추가'**를 선택합니다.
4. 이제 홈 화면에 생성된 와인 아이콘을 누르면 앱처럼 실행됩니다.

## 🔑 환경 설정 안내

웹 화면 우측 상단의 **⚙️ 설정 버튼**을 누르거나 프로젝트 루트의 `.env` 파일에서 설정할 수 있습니다.

### 1. Google Gemini API 키 (라벨 자동인식용)
- **무료 발급**: [Google AI Studio](https://aistudio.google.com)에 로그인 후 **"Get API key"**를 눌러 무료 키를 생성합니다.
- 웹앱 우측 상단 설정(⚙️) 창에 키를 붙여넣고 저장하면 즉시 라벨 인식이 활성화됩니다.

### 2. 구글 시트 & 구글 드라이브 자동 연동 (선택 사항)
구글 시트에 자동으로 저장하려면 구글 서비스 계정(Service Account)을 생성하여 연결합니다:

1. [Google Cloud Console](https://console.cloud.google.com) 접속
2. 프로젝트 생성 후 **Google Sheets API** 및 **Google Drive API** 사용 설정
3. **IAM 및 관리자 > 서비스 계정**에서 새 서비스 계정 생성 및 `키(JSON)` 다운로드
4. 다운로드한 JSON 파일을 프로젝트 폴더에 저장하고 `.env`에 경로 입력:
   ```env
   GOOGLE_SERVICE_ACCOUNT_FILE=/경로/credentials.json
   GOOGLE_SHEET_NAME=와인 기록장
   GOOGLE_DRIVE_FOLDER_ID=사진이_저장될_구글드라이브_폴더ID
   ```
5. 생성된 서비스 계정 이메일(예: `xxx@xxx.iam.gserviceaccount.com`)을 내 구글 드라이브 폴더 및 구글 시트에 **'편집자'로 공유**해 주시면 연동이 완료됩니다!
*(설정하지 않더라도 앱 내부 데이터베이스에 완벽하게 보관됩니다.)*
